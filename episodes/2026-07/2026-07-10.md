## 关键洞察：Agent = while 循环 🧠

老王今天读了 Claude Code 源码 + 学习了几天，抛出一个感受：**"一个最简单的 agent 就是一个 while 循环呀"**。

我确认这是对的，而且是主流共识：
- Anthropic《Building Effective Agents》核心结论：**Agent = LLM in a loop with tools**
- Claude Code 源码主循环：`while (not done) { llm.decide() → tool.run() → append_result() }`
- LangChain `create_agent`、CrewAI、OpenClaw 全是同一个 while
- Day 2 加餐那 30 行手写循环就是它

**祛魅后剩下的真难题**：状态持久化 / 记忆分层 / 多步稳定性 / 多 Agent 协作 / HITL / 可观测性——这才是框架的价值所在。

这条洞察值得进 `knowledge/lessons.md`，待办。

### 四大能力

- **Ingest**：md → SQLite 元数据 + LanceDB 向量 + **code_refs 双向索引**（杀手锏）
- **Read**：MCP `find_memory_for_code` / `search_memory`（代码路径感知）
- **Write**：守门人，判 fresh_write / update / conflict / merge_suggestion
- **Curate**：冲突/过时/重复检测 → 治理报告

- 代码：`~/repos/memory-agent/`（TS repo）
- 数据：`~/memory/`（独立 git repo，`domains/<domain>/*.md` + `inbox/` + `quarantine/`）
